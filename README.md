## How to Run

You need a C++ compiler such as GCC or MinGW.

Compile a source file:

```bash
g++ -std=c++17 solution.cpp -o solution
```

Run on Windows:

```bash
solution.exe
```

Run on Linux or macOS:

```bash
./solution
```

Replace `solution.cpp` with the name of the source file you want to compile.
